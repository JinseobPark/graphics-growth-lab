# Graphics Growth Lab

Graphics Growth Lab is a personal daily knowledge base for growing as a graphics engineer.

This repository collects short, structured Markdown notes about computer graphics, GPU programming, rendering pipelines, simulation, visualization, and related engineering topics.

The goal is not to store toy projects or daily coding exercises.  
The goal is to continuously build conceptual depth that can support real-world graphics engineering, technical interviews, portfolio direction, and long-term career growth.

## Purpose

I use this repository to read, understand, and accumulate one graphics-related concept every day.

Each note focuses on:

- GPU architecture and compute-oriented thinking
- Real-time rendering pipelines
- Shader and memory layout perspectives
- Simulation and visualization concepts
- Practical graphics engineering trade-offs
- Interview and portfolio relevance

## Note Format

Each daily note follows a consistent structure:

1. Today's Concept
2. One-line Core Idea
3. Why It Matters
4. Implementation Perspective
5. Connection to My Interests
6. Three Questions to Keep in Mind
7. One Graphics Engineer Interview Question and Answer
8. Portfolio / Career Connection
9. Next Concept to Continue
